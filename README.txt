# AM store | AM STORE

نسخة تجريبية لمتجر ملابس وأحذية وإكسسوارات.

## التشغيل
1. افتح `index.html` في المتصفح.
2. لوحة صاحب المتجر: افتح `admin.html`.
3. كلمة المرور التجريبية: `naqsha2026`.

## الصور
أنشئ مجلد `images` وضع فيه صورة الواجهة باسم:
`hero.jpg`

يمكن للأدمن رفع صور المنتجات مباشرة من `admin.html`.

## مهم جدًا
هذه النسخة Prototype تعمل باستخدام LocalStorage/SessionStorage.
كلمة مرور الأدمن موجودة داخل JavaScript، لذلك لا تعتبر حماية حقيقية على موقع منشور.

عند الانتقال إلى الإنتاج يجب استخدام:
- Backend
- قاعدة بيانات
- تسجيل دخول حقيقي وآمن للأدمن
- تخزين صور على خادم/خدمة تخزين
- API لإدارة المنتجات والمخزون والطلبات.

رقم واتساب المتجر موجود في `js/app.js` ويمكن تغييره من الثابت `STORE_PHONE`.
